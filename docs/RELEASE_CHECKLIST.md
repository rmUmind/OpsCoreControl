# OpsCoreControl 1.1.0 — release checklist

## Автоматические проверки

- [x] Debug Rebuild, WarningLevel 4: 0 ошибок, 0 предупреждений.
- [x] XAML компилируется, все окна и словари ресурсов включены в проект.
- [x] Все обработчики событий из XAML сопоставлены с методами C#.
- [x] Встроенные ресурсы CryptoPro, CryptoPro Plugin, Cisco AnyConnect и Assistant доступны в сборке.
- [x] Read-only smoke test: процессы, службы, автозагрузка и hosts.
- [x] Release startup smoke test: приложение и главное WPF-окно успешно запускаются.
- [x] Защита от завершения OpsCoreControl и критических процессов.
- [x] Защита текущего и системных профилей от удаления.
- [x] Проверка сетевых путей, букв дисков и адресов диагностики.
- [x] Повреждённые размеры/координаты окон заменяются безопасными значениями.
- [x] Журналы старше 30 дней удаляются, файл ограничен 5 МБ.
- [x] Классический/современный интерфейс и тема сохраняются в пользовательских настройках.

## Ручной smoke test перед публикацией

Выполнять на тестовом ПК или виртуальной машине от администратора.

- [+] Открыть каждую вкладку и проверить обновление её списка.
- [+] Проверить светлую и тёмную темы в классическом и современном интерфейсах.
- [+] Открыть полный дашборд, проверить прокрутку, Topmost, отчёт и повторное открытие.
- [+] Выполнить обычный Ping, непрерывный Ping и остановку команды.
- [+] Проверить чтение System/Application Event Log.
- [+] Запустить безопасную системную оснастку, например `services.msc`.
- [+] Проверить запуск каждого установщика и отменить его до внесения изменений.
- [+] Проверить управление тестовой службой и тестовой записью автозагрузки.
-  [+] Проверить сетевой диск на тестовой шаре.
- [+] Проверить файл подкачки только на тестовой системе с контрольной точкой.
- [+] Проверить очистку только на подготовленных тестовых папках.
- [+] Проверить отказ удаления текущего профиля и завершения самого OpsCoreControl.
- [+] Проверить 100%, 125%, 150% и 200% DPI.
- [+] Проверить Windows 10 и Windows 11 без Visual Studio/.NET SDK.
